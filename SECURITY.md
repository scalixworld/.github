# Security Policy

## Reporting a Vulnerability

**Please do not open public GitHub issues for security vulnerabilities.**

If you discover a security issue in any Scalix Cloud service, SDK, CLI, MCP integration, or public repository, please report it privately to:

- **Email:** [`security@scalix.world`](mailto:security@scalix.world)
- **Disclosure policy:** [`https://scalix.world/.well-known/security.txt`](https://scalix.world/.well-known/security.txt) & [`https://scalix.world/legal`](https://scalix.world/legal)

## What to Include

To help us triage and resolve reports quickly, please include:

- The affected asset, endpoint, package, or repository
- Clear steps to reproduce or a minimal proof of concept
- Potential security impact

## Coordinated Testing Rules

- Only test against your own account and test projects — never access or modify other tenants' data or disrupt production availability.
- If you need a dedicated test client or environment to verify a fix, email [`security@scalix.world`](mailto:security@scalix.world) and we will provision one.
